# Precificação ótima para microcomerciantes

Trata-se de uma ferramenta em Python que modela como o preço afeta as vendas e o lucro de microcomerciantes, como vendedores ambulantes de doces ou produtos alimentícios, artesãos que produzem itens como pulseiras de pano, e quem fabrica em casa itens para vender em marketplaces, como eBay, Mercado Livre e Shopee. A partir do custo do produto, das taxas envolvidas e de dados reais de venda, o modelo estima o preço que maximiza o lucro, além de simular, de maneira simplificada, o impacto de descontos e aumentos. Embora seja um modelo inicial e simplificado, o projeto pretende ajudar microcomerciantes que dependem dessas vendas como fonte de renda ou renda extra.

## Motivação

Este projeto nasceu do Checkpoint 3 da disciplina *Differentiated Problem Solving*, do 1º semestre de Engenharia de Software da FIAP, ministrada pelo Prof. Me. Eng. Rodolfo Magliari de Paiva em 2026.2. A proposta pede a modelagem matemática de um problema simples e real, com pelo menos dois tipos de funções, e sua implementação em Python.

A atividade original foi proposta em grupo. Este repositório é um desenvolvimento individual e aprofundado, feito com fins de estudo e portfólio. O modelo foi construído com hipóteses simplificadoras, compatíveis com os conteúdos do semestre, mas pensado para ser aperfeiçoado à medida que novos conhecimentos forem adquiridos.

Os requisitos da proposta estão resumidos em [docs/00-proposta.md](docs/00-proposta.md).
